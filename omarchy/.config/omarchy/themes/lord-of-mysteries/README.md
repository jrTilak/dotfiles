# Lord of Mysteries

A professional dark Omarchy theme inspired by *Lord of Mysteries*: charcoal-indigo fog, luminous parchment text, antique-gold ritual accents, vivid violet mysticism, and controlled crimson danger. The base luminance stays close to Catppuccin Mocha, while richer semantic colors and stronger focus states remain clear without turning neon.

## Palette

- Fog blue: `#7AAEE8`
- Crimson: `#E06C88`

## Generation notes

Generated with OpenAI's built-in image generation in reference-guided mode. The common art direction requested balanced mid-dark exposure, antique gold and violet accents, clean anatomy, no text or logos, and a desktop-safe 16:9 composition. Character-specific prompts added canonical wardrobe, setting, mood, and props without copying the reference images' layouts. The first six use cinematic dark-fantasy realism and painterly texture. The sixth used a user-supplied composition reference and specifically requested a distant full seated silhouette, concealed face, low layered gray fog, monumental cathedral architecture, and a restrained supernatural aura. The final two use polished manga/manhwa and black-ink graphic-novel rendering for more energetic fight scenes.
